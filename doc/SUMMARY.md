### 一、长官需求与移动端重构落地

根据长官最新指示：“还需要在手机上使用，但是使用体验并不好，点击答案后，如果有解释那么会把按钮顶下去”。针对手机小屏幕刷题中“解析撑开发生跳动、频繁滑动找按钮”的核心交互痛点，系统实施了系统性的移动端交互重塑：

#### 1. 核心突破：底部吸底悬浮操作栏（Sticky Bottom Action Dock）
- **痛点彻底根治**：在手机端（屏幕宽度 $\le 768\text{px}$ 时），将【上一题】、【下一题】、【★ 收藏本题】等核心操作按钮自动吸附在**屏幕最底部**（带磨砂玻璃高斯模糊质感与阴影）；
- **按键触手可及**：无论上方题干有多长、解析卡片展开多少行，**【下一题】和【上一题】按钮永远稳稳停留在屏幕底部右手大拇指舒适区**，做完题无需上下滑动即可盲点切换，彻底消灭“解析顶飞按钮”导致的上下频繁滚动；
- **全屏与安全区适配**：增加 `padding-bottom: max(12px, env(safe-area-inset-bottom))`，全面避让 iPhone Home 指示条与安卓手势返回条，避免误触。

#### 2. 顶部导航与分章筛选横向滑轨（Horizontal Scroll Track）
- 顶部 7 大模块 Tab 改为**原生手感单行水平滑轨**（`overflow-x: auto; white-space: nowrap`），隐藏浏览器原生滚动条，彻底解决多行折行堆叠占用屏幕的问题；
- 分章下拉框与题号跳转控制面板紧凑化网格排布，垂直空间节省 **40% 以上**，留出足够视野给题目。

#### 3. 手机触控热区与排版紧凑化
- 题目卡片外边距与内边距缩减为手机舒适的 `0.9rem ~ 1.1rem`；
- 选项卡片加大触控高度（最小高度 44px），并增加触摸按下的弹性微缩反馈（`active: scale(0.98)`），防误触且手感利落；
- 切题时手机端自动平滑复位至卡片顶部，避免长解析翻题后依然停留在底部的错位感；
- 适配包括【基础单选】、【专项强化单选】、【全真模考】、【章节与必背简答】在内的所有核心模块。

### 二、系统当前核心模块全景

1. 📝 **基础实战单选 (365题)**：20章基础全量选择题 + 章节筛选 + 随机特训 + 黄金单选 + 时政100题；
2. 🎯 **专项强化单选 (740题)**：马原（520题）+ 史纲（220题）全量专项题库，支持分科分卷智能筛选；
3. 📖 **章节简答 (50题)**：20章基础全量简答/论述题 + 分章抽背 + 遮挡默背 + 采分点高亮；
4. 🏆 **黄金模考·自由做题 (41题)**：35 单选 + 4 简答 + 2 论述，配答题草稿纸与踩分对照；
5. 📋 **必背简答 (32题)**：成考考前 32 道压轴必背简答汇总；
6. ⏱️ **历年真题与预测模考 (8套卷)**：4 套历年真题 + 4 套 2026 预测卷 + 1 套黄金卷 + 极速快测；
7. 📕 **错题与复习本**：错题消灭机制 + 重点标记收藏夹（全面支持基础题、专项题与各大真题卷）。

### 三、质量红线与提交前 7 步自检

1. **类型与语法兼容（Rule 1.3）**：全局 `.includes(...)` 严格为 **0** 处，100% 采用兼容性最好的 `indexOf(...) >= 0`；
2. **生产环境红线（Rule 4.1）**：全局 `console.log` 残留严格为 **0** 处；
3. **VM 自动化沙箱质检**：
   - 全题库数据完整校验；
   - 核心功能（单选判题、吸底切题、模考交卷等）在沙箱内无异常全量通过；
4. **版本控制**：修改与生成文件均已纳入 Git，提交并同步推送到远程 `main` 分支。
