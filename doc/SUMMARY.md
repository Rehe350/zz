### 一、问题根因诊断与技术突破

#### 1. 现象分析（以第42题为例）
长官指出：在读取《考前冲刺资料——政治.pdf》生成挖空时，加粗的黑体、普通红体和加粗红体存在未显示的问题，且部分题目如第42题《内容与形式》丢失了前置概念定义与第三分论点。

- **旧版问题**：
  1. 早期脚本采用粗粒度纯文本提取，丢失了 PDF 中的色彩空间（`rg`/`setFillRGBColor`）和字形渲染模式（`Tr`/`setTextRenderingMode`）；
  2. 提取阶段对题目进行了简化摘要，导致第42题仅剩一句简述，彻底遗失了前置的“内容”与“形式”定义以及第3分论点；
  3. 单一的 `{{blank:...}}` 标签无法表达“加粗黑体”、“加粗红体”、“普通红体”三个不同层级的视觉权重。

#### 2. 底层解码公式与技术突破
通过直接解析 PDF 的操作符算子流（Operator List），破解了该 PDF 由 Word 导出的排版规律：
- **颜色识别**：通过 `OPS.setFillRGBColor` 捕获当前笔刷 RGB，判定红色（R高、G/B低）或黑色；
- **字重识别**：Word 导出中文粗体时，使用的是 **Text Rendering Mode 2（描边+填充，`renderMode === 2`）**；常规字体使用的是 **Mode 0（仅填充，`renderMode === 0`）**；
- **四维精准映射**：
  1. **加粗红体**（`bold-red`）：RGB红 + renderMode 2 -> `<strong class="hl-bold-red">...</strong>`（核心考点概念词）
  2. **普通红体**（`regular-red`）：RGB红 + renderMode 0 -> `<span class="hl-red">...</span>`（分点核心得分词）
  3. **加粗黑体**（`bold-black`）：RGB黑 + renderMode 2 -> `<strong class="hl-bold">...</strong>`（结构词、题号、分点序号）
  4. **普通黑体**（`black`）：RGB黑 + renderMode 0 -> 普通正文（概念阐述与过渡句）
