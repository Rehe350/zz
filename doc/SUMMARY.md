### 一、新模块背景与功能定位

根据长官最新指示，将 `【4】26成考《政治》32道简答汇总.pdf` 完整 32 道必背核心简答题全量录入系统，专门打造独立的 **【必背简答 (32题)】** 深度背诵模块，杜绝大模型断连异常，保障考前高频短平快默背冲刺。

系统现涵盖 7 大完整学习与测试模块：
1. **📖 考点背诵与自测**：219条考纲核心考点挖空与自测；
2. **📝 基础实战单选 (354题)**：马原毛概(119)、习思想(100)、黄金模考(35)、时政热点(100)、随机特训(30)；
3. **🎯 历年真题变式 (657题)**：真题衍生题高频实战；
4. **🏆 黄金模考·自由做题 (41题)**：大卷单选、简答、论述自由拆分作答；
5. **📋 必背简答 (32题)**：【新增】成考高频 32 道主观简答题专项背诵系统；
6. **⏱️ 全真限时模考**：全真模拟实考与倒计时；
7. **📕 错题与复习本**：错题与收藏夹闭环复习。

### 二、32道必背简答模块核心特色

1. **题目结构与智能分类**：
   - **马哲原理 (1~15题)**：运动与静止、意识能动性、辩证法分歧、对立统一规律、实践决定认识、反映论、社会存在与社会意识、人类社会发展、社会进步、人的本质、人民群众史观、真理与谬误、群众路线、矛盾动力、辩证否定观；
   - **毛概与特色 (16~22题)**：国体与政体、社会意识相对独立性、政治体制改革原则、反腐败斗争、社会主义本质两目标关系、按劳分配原因、农业基础地位；
   - **邓论与初级阶段 (23~32题)**：政治体制改革目标任务、邓小平理论时代地位、本质论述、发展生产力、三个有利于、初级阶段含义、改革是第二次革命、初级阶段基本路线、长期性原因、科学技术是第一生产力。
2. **双背诵模式**：
   - 📖 **全文背诵模式**：结构化清晰展示标准答题各要点，逻辑序号鲜明（高亮重点序号），利于通读速记；
   - 🙈 **遮挡抽背模式**：答案默认折叠遮挡，学员可在脑海中先默背要点，再点击揭晓对照，实现考前自测。
3. **进度与掌握统计**：
   - 实时记录掌握题数与百分比进度条（如 `已掌握 12 / 32 题 (38%)`）；
   - 一键标记“已掌握 / 待背诵”，数据持久化保存在浏览器本地（`localStorage`）。
4. **辅助工具链**：
   - 🎲 **随机抽背**：打破顺序记忆定势，随机抽背任意题目；
   - 🔊 **语音朗读**：调用原生 Web Speech API 进行标准普通话朗诵磨耳朵；
   - 📑 **题目目录速览**：抽屉式展开 32 题完整网格清单，快速定位直达；
   - 🔢 **题号快速跳转**：支持输入 1~32 秒级切换。
